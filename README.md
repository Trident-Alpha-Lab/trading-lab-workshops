# Trading Lab Workshops

Practical, self-contained workshops for learning quantitative market research workflows with Python, local AI coding assistance, Git and GitHub.

These workshops are intended for **research and education only**. They do not connect to brokers, place live trades, or provide investment advice.

## Workshops

### [Workshop 1 — EUR/USD Indicator Lab](./workshop-1/)

A one-hour introductory workshop for Windows users. It sets up a free local research stack and runs a first reproducible experiment on daily EUR/USD data using a small set of simple indicators.

The workshop covers:

- Windows Terminal / PowerShell
- Git and GitHub
- Python managed with `uv`
- local AI coding assistance with Ollama
- daily EUR/USD data
- moving averages, RSI, momentum and volatility
- simple forward-return tests
- charts and saved results
- committing the experiment to GitHub

No broker integration or live trading is used.
